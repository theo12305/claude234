# materials: material list and horizontal piping

A feature package that registers itself (hidden on the page for now; the code is kept). It is the example for
new features: logic without Streamlit, a `page.py` that registers a result view, its own `de.py`.

| File            | What it does                                                         |
|-----------------|----------------------------------------------------------------------|
| `network.py`    | trench routing (automatic or drawn), plain geometry                  |
| `quantities.py` | the material list (bill of quantities, no prices) from the sizing    |
| `page.py`       | the result view: plan, settings, table, downloads                    |
| `de.py`         | German texts of this package                                         |
